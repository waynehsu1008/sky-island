# 空中之島

使用 three.js 的單人方塊小島，已實作 STEP 0～8：走路、跳躍、挖掘、掉落、拾取、放置、晝夜變化，以及長方體手臂、手持方塊、小動物與遊玩計時。

另依使用者最新要求，右下角手臂改為 Minecraft 風格的長方體，沒有手掌或手指，以自製像素膚色與藍綠色袖子呈現；保留走路擺動、挖掘揮動與放置伸手，暫停時隱藏。手臂只需兩個繪製批次。

選取有庫存的方塊時，手上會顯示同種類的 3D 方塊，沿用地形素材包與各面材質；切到其他有庫存種類會同步切換，零庫存或放完最後一格後恢復空手。手持方塊跟隨手臂擺動，不影響世界碰撞或扣除庫存，只多一個繪製批次。

島上加入 2 隻小豬、1 隻綿羊、2 隻小雞，皆為自製方塊模型，會漫遊、轉向、停下與擺腿；遇到障礙或島邊會停下轉向。腳下被挖掉時落到下層，跌入虛空會回到安全空地。暫停與切到背景時動物也停止；目前提供觀賞與陪伴，沒有攻擊、飼養或繁殖功能。五隻動物共用一個實例繪製批次。另有方塊雲、直角介面與石灰色方塊欄。

## 本機執行

需要 Node.js 與 pnpm。在此資料夾執行：

```sh
pnpm install
pnpm dev
```

開啟終端機印出的本機網址，按「開始探索」後操作：WASD 移動、空白鍵跳躍、滑鼠看四周、長按左鍵挖方塊、走近拾取、數字鍵 1～8 選方塊、右鍵放置、Esc 暫停。右上角可切換全螢幕、查看時段與 FPS。需使用具鍵盤、滑鼠並支援 WebGL 2 的桌面瀏覽器。

準心對著 5 格以內的方塊長按左鍵，會出現逐步加深的裂痕；泥土與草地需要 0.75 秒、石頭需要 2 秒。放開左鍵、換目標、看向天空或暫停都會清除進度。每挖一格會彈出同種類小方塊，靠近 1.5 格內會飛向角色，完成吸取後方塊欄才加 1；3 格外不會拾取。

選有庫存的種類，對準既有方塊的表面按右鍵，在該面相鄰的空格放置，成功才扣 1。不能放進角色身體、出生點站立空間、已占用位置或世界外。出生點腳下那一格不能挖除。遊戲每 300 秒完成一整個晝夜循環，夜晚保留照明，暫停或切到背景時不推進遊玩時間。

左上角顯示天數與累積遊玩時間：從「第 1 天／00:00」開始，累積遊玩滿 5 分鐘變成第 2 天、滿 10 分鐘變成第 3 天，與晝夜共用同一個計時來源。超過一小時改為時分秒顯示；開始前、暫停與切到背景時不計時，重生會保留當次時間，重新整理則重置。

```sh
pnpm test       # 一次執行全部自動測試
pnpm build      # 產生 dist/ 靜態網站
pnpm preview    # 本機預覽建置結果
```

部署只需提供 `dist/` 內的靜態檔案，不需要遊戲後端。開發預覽使用的本機靜態服務不負責保存遊戲狀態。

## 開發進度

- STEP 0：基本小島與角色操作；學校舊電腦的全螢幕效能待實測。
- STEP 1：長按挖掘、十階段裂痕、中斷重設與出生點地板保護。
- STEP 2：同種類 3D 掉落物、旋轉、重力、落地及承接面變更。
- STEP 3：自動吸取、一次計數、八種類型方塊欄與素材包圖示。
- STEP 4：上面與側面相鄰放置、數量扣除、空間與邊界檢查。
- STEP 5：5 分鐘晝夜循環、平順天色與光線、夜間最低照明。
- STEP 6：無手指的長方體手臂、走路／挖掘／放置動作，有庫存才顯示對應手持方塊。
- STEP 7：2 隻小豬、1 隻綿羊、2 隻小雞的漫遊與地形反應，方塊雲及方塊風格介面。
- STEP 8：累積遊玩時間、每 5 分鐘增加一天、暫停停止計時與重生保留時間。

上一輪 52 項自動測試與正式建置通過，包含動物地形行為，以及計時起點、300 秒換日、暫停與超過一小時的格式。瀏覽器已驗證白天與夜晚畫面、動物移動與暫停、無手指手臂、手持方塊隨庫存切換、放完恢復空手、計時暫停與第 2 天天數顯示、挖撿放整串流程、數量守恆與窄螢幕排版。晝夜循環與天數以自動化虛擬時間快轉驗證；學校舊電腦全螢幕的 60 秒效能量測仍待實機確認。`VERIFY.md` 保留原有老師測試，補上重生與 STEP 6～8 驗收，既有核取狀態不變，新增項目待使用者實際驗收後勾選。

掉落重生保留當次遊玩的世界與方塊欄；重新整理網頁會重新開始。需求、驗收與實作順序分別見 `BRIEF.md`、`VERIFY.md`、`PLANS.md`。
